## How I use generative AI in operations

An engineer may start a shift with incomplete tickets and several pages of notes. I use LLMs to organize the observations, draft a plain-English update and suggest questions for the next shift. A technician checks the proposed explanation against logs and test results. For repeated questions, RAG can retrieve an approved runbook and show the passage behind an answer. If good evidence is missing, the issue goes to a person.

For automation projects, I map the manual steps, define where approval belongs, connect the APIs and test the failure path. For data work, I reconcile source records, separate exceptions and explain how I counted the results. Clients can start with one workflow, one ticket queue or one batch of records.
